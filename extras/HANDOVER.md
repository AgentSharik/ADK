## 1. Что это за проект

**ADK (Active Directory Kit)** — наша настольная утилита для администраторов домена: PyQt6 + ldap3 + pywin32 (Windows), SQLite (для 1–3 админов) или PostgreSQL (`adk --serve`). Начиналась как мой однофайловый монолит; после аудита переработана в пакет `adk/`, снабжена тестами, документацией и отчётом. Позиционируется как портфолио-проект.

Продукт везде называется **ADK**. О прежнем названии — только слово «ребрендинг», само имя не писать нигде и никогда. Есть версия коллеги (модульная, «его») — с ней мы **не сливаемся**, ничего ему не передаём, тему не поднимаем.

### Основные возможности (кратко; полный список — `docs/FEATURES.md`)
- **Поиск** по ФИО, логину, почте, отделу, кабинету, имени ПК, IP, принтеру (без телефонов). Живой, неблокирующий. По IP находит принтер и показывает только его.
- **Таблица**: колонки по умолчанию — Логин, ФИО, Учётка, Имя ПК, Сеть, Телефон, IP-тел; остальные включаются чек-листом. ФИО — только имена (в таблице «Фамилия И.О.», в инспекторе полностью), никогда логин. Фильтры «Архивы (все ПК пользователя)» и «Отключённые учётки».
- **Инспектор** справа: данные пользователя, состояние сети ПК, кнопка «Пинг», блок «Действия с ПК»: RMS, Диск (C$ или меню томов), Управление ПК, **Питание ПК** (меню: разбудить WoL, заблокировать экран, выйти из пользователя, сон, перезагрузить, выключить), Здоровье ПК, Установленное ПО, Входы за 24 ч; принтеры ПК с живым опросом. Нет строки «Был в сети».
- **Карточка пользователя** (переработана): шапка с ФИО и бейджем «Активна / Не активна», кнопки Копировать / Заметки / История / Группы как у… / Смена пароля / Снять блокировку / Отключить-Включить; вкладки Профиль (поля в две колонки, чекбоксы смарт-карта и Lync), Группы (две панели, фильтр, ±), Учётная запись, Характеристики ПК. Снятие блокировки → предложение задать новый пароль.
- **Роли** (`adk/access.py`, по группам AD из `[Access]` в config.ini): право «ПК» и право «AD». Роль «ПК» (админ на компьютерах, AD только чтение): всё про ПК работает, а изменения AD скрыты — смена пароля, блокировка, отключение, «Сохранить», группы ±, новый пользователь, массовые операции; поля readonly, чекбоксы заморожены; в карточке жёлтая плашка, в шапке бейдж «AD: только чтение», на дашборде карточка «Роль». Роль «AD» — полный доступ.
- **Дашборд**: честные цифры «ПК в сети / не в сети / рабочих станций в AD» (сходятся с поиском), карточка «Внимание» (блокировки, учётки без входа, ПК давно не в сети — **без** пунктов про истечение пароля), карточка «Роль», недавние поиски, быстрый доступ.
- **Здоровье ПК**: Обзор, Диски (S.M.A.R.T. как CrystalDiskInfo), Карта диска (ручной обход как WinDirStat, объёмные плитки, выбор тома «таблеткой», таблицы Папки/Файлы/Почистить/Профили **справа**), Ошибки (журнал Windows, уровни, период с/по), **Диагностика** (заглушка «здесь пока пусто»).
- **Пинг**: окно с индикатором, живым графиком, статистикой, единой лентой журнала (по умолчанию только события). Офлайн-ПК не отвечает (согласовано со статусом «Сеть»).
- **Сеть**: Свободный IP (карта подсети 32×8 с просветами, легенда справа, сверка с DHCP, найденные за сеанс), массовый пинг + WoL, принтеры парка (без виртуальных принтеров), сравнение ПК, ПО парка, Excel-опись с предпросмотром.
- **AD-операции**: смена пароля (одно окно, без QR), блокировки, группы, массовые операции, новый пользователь с шаблонами (Бухгалтер и т.п.), журнал действий, уведомления только по SMTP, баннер проверки версии (без автообновления).
- **Оформление**: 10 тем, свой выбор цвета (собственный диалог, не стоковый Qt), окно входа в стиле программы, безрамочные диалоги, скроллбары заметные, таблицы с разделителями строк и акцентной полоской у выбранной строки.
- **Учётные данные**: «Запомнить меня» — Windows DPAPI (win32crypt или ctypes/crypt32), иначе keyring; причина отказа показывается; данные стираются только при ошибке учётных данных, не при сетевой; пароль подставляется в окно входа.

### Чего делать НЕЛЬЗЯ (решения автора)
- Не реализовывать «Сессии на ПК» (query user / msg / logoff-сессий) — зарезервировано за автором.
- Не возвращать Telegram, автообновление, QR-коды, «временный пароль», пункт «Был в сети», упоминания «кэш» в интерфейсе.
- Никогда не писать AnyDesk (только RMS), прежнее имя продукта, реальные домены/UNC/ФИО.
- Не предлагать слияние с проектом коллеги.

## 4. Порядок работы над партией правок

### 4.1 Тесты — обязательны для каждой функции и каждого исправления
Инфраструктура в `tests/test_gui.py`: заглушка LDAP (`FakeConn`, `FakeEntry`, `ENTRIES` — ivanov активный/WS-101 в сети, petrov отключён), фикстуры `qapp`, `fake_conn`, помощники `_main(qapp, fake_conn, monkeypatch)` (главное окно) и `_wait(cond, app, ms)`. Импорт: `from tests.test_gui import ENTRIES, FakeEntry, _main, _wait, fake_conn`.

Куда класть: `test_core` (логика, БД), `test_gui` (главное окно, инспектор), `test_accounts` (карточка, учётки, роли, вход, дашборд-роль), `test_fleet` (парк, доступ), `test_health`, `test_ping`, `test_network` (свободный IP, DHCP), `test_tools`, `test_ui` (геометрия, темы, окно входа), `test_learning` (учебные, для автора).

Стиль:
- docstring по-русски: **что проверяем и почему** («3.3.0: раньше … → теперь …»); шаги — комментариями;
- всё внешнее подменять `monkeypatch`: `mw.subprocess.Popen`, `mw.netutils.subprocess.run` (фоновый arp), `MessageBox.question`, сеть; ничего реального не запускать;
- роли: `access.set_rights(pc=…, ad=…)` и в `finally` — `access.reset()`;
- offscreen-экран 800×600: окна не выше; после `show()` — `qapp.processEvents()`; новый виджет в показанном окне — `layout().activate()`;
- при изменении поведения сначала обновить существующий тест, не удалять;
- команды удалённых действий идут на **IP/имя цели**, не на имя ПК из таблицы — не проверять «WS-101» в argv.

Автор — новичок в тестах: объяснять без жаргона, на примерах его кода.

## 5. Стандарты интерфейса и поведения (накопленные требования автора)

- **Язык**: весь промежуточный текст, комментарии в коде, docstring, титры, сводки — по-русски.
- **Учётка**: бейдж ровно двух состояний «Активна / Не активна» (pill-стиль), инспектор не дублирует «НЕ АКТИВНА — …».
- **Поиск**: без телефонов; по IP — и принтеры (показывать только принтер); быстрый, неблокирующий.
- **Таблицы везде**: ширина колонок по тексту (или перенос на 2 строки), видимые разделители строк (в т.ч. выделенных), вертикальные линии, толстая короткая акцентная полоска слева у выбранной строки. Скроллбары контрастные. Заполнение QTableWidget — при выключенной сортировке.
- **Инспектор**: «Диск» → C$ сразу или стилизованное меню томов (`QMenu#diskMenu`); «Питание ПК» — то же меню-стиль; нет «Был в сети»; принтеры без виртуальных (PDF/XPS/OneNote/Fax).
- **Карточка**: без дублей быстрых действий инспектора; AD-атрибуты, группы, пароль/блокировка/отключение, привязка ПК, характеристики ПК только чтение.
- **Пароли**: одно окно «Смена пароля», без QR и «временного»; «Внимание» без пунктов про истечение пароля.
- **Здоровье**: сканирование карты диска только вручную; тома выбираются, выбранная плитка подсвечена, плитки объёмные, ничего не наезжает, таблицы справа от карты, «Почистить» — подмножество тех же данных (ничего не выдумывать для несистемных томов); окно 1240×720.
- **Свободный IP**: сверка с DHCP; цвет ячейки = статус, найденный остаётся зелёным с рамкой; просветы между ячейками, легенда справа.
- **Сравнение ПК / ПО**: живой опрос, сохранённый список — только если ПК недоступен, с датой; слово «кэш» пользователю не показывать.
- **Дашборд**: цифры честные и сходятся с поиском.
- **Цветовой пикер**: свой дизайн; превью «было» = «стало» по размеру и шрифту.
- **Шапка**: эмблема + «ADK», без кнопки «Выход», окно разворачивается/полноэкранно; логотип прозрачный.
- **БД и CSV**: ничего нового не должно их портить; живой опрос принтеров БД не меняет.
- **Ping-окно**: журнал по умолчанию — только события, консольный текст опционально, чипы по ширине текста, один шрифт; состояние согласовано со статусом «Сеть». **Ожидается полная переработка окна пинга — автор ещё не описал, как хочет.**
- Автор не сетевой эксперт: DHCP, PTR, WoL и т.п. объяснять простыми словами, когда спрашивает.

## 7. Технические грабли (чтобы не наступать повторно)

- Никогда `open(p,'w').write(open(p).read()…)` одной строкой — запись обнуляет файл до чтения. Патчить через Python-скрипт с `assert a in s` перед заменой; после — проверять grep.
- e2e-скрипты: `PYTHONPATH=/home/user QT_QPA_PLATFORM=offscreen`, из корня, фильтр `grep -v propagate | tail -n 1`.
- `pytest -q` для лога отчёта не годится — `make_report.py` читает `-v`.
- Offscreen: без `apply_theme` окна без стилей; экран 800×600; `WA_TranslucentBackground` в QScrollArea даёт мусор; QTableWidget заполнять при выключенной сортировке; при очистке QLayout через `takeAt` stretch-элементы возвращают `widget() is None`.
- Юникодные глифы кнопок окна рисуются квадратами — использовать `QStyle.standardIcon`/текст. Emoji-шрифты ставить (`fonts-noto-color-emoji`).
- `PRESET_THEMES` сплошные темы без `c1/c2` — брать `bg`. `app_palette()` возвращает объект `Palette` (атрибуты `text`, `subtext`, `title_accent`, `danger`…), не dict.
- Пути Windows в JSON здоровья — через `ntpath`. `LIKE … ESCAPE '\\'` в обычной строке Python.
- Демо: `ad.reset_password` требует `conn.extend.microsoft.modify_password` — в `FakeConn` подставлять `_Ext()`; стаб `PingWorker` должен иметь сигналы `ping_event`, `error`; диалоги по центру перекрывают шапку — `dlg_origin`.
- reportlab `Paragraph` не понимает `<wbr/>`. pyflakes игнорирует `# noqa: F401` — использовать `__all__`.
- Реальный `.exe` в песочнице собрать нельзя (CI `build-exe.yml` делает это на GitHub).
- Не переписывать существующие методы «по памяти» при рефакторинге — копировать оригинал.
