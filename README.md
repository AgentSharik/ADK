# ⚡ ADK — Active Directory Kit

![tests](https://github.com/AgentSharik/ADK/actions/workflows/tests.yml/badge.svg)
![python](https://img.shields.io/badge/python-3.10%2B-blue) ![Qt](https://img.shields.io/badge/PyQt-6-41cd52) ![license](https://img.shields.io/badge/license-MIT-lightgrey)

**Набор инструментов системного администратора Active Directory в одном exe.**
Один запрос — и на экране сотрудник, его ПК, IP и статус сети, телефон, принтеры, здоровье ПК, заметки коллег
и кнопки удалённых действий. Вокруг поиска — инструменты для парка: массовые операции, сводка «Внимание»,
массовый пинг + WoL, установленное ПО, журнал действий, роли, плагины, CLI.

**Стек:** Python 3.10+ · PyQt6 · ldap3 · SQLite — один файл базы, без сервера СУБД. Windows-инструменты (PowerShell, DPAPI, RMS); ядро и тесты кроссплатформенные.

## ✨ Что умеет

- **🔍 Единый поиск** — фамилия, логин, почта, отдел, **имя ПК или IP** (принтер по IP находится сам). Телефоны намеренно не ищутся.
- **🧭 Инспектор** — ПК, IP, живой статус сети, «Учётная запись» (блокировка, срок пароля), принтеры (снимок и **живой опрос**), заметки, история «кто сидел», действия: RMS, C$, `compmgmt`, перезагрузка, пинг, WoL.
- **🩺 Здоровье ПК** — обзор, **S.M.A.R.T.** (аналог CrystalDiskInfo), **карта диска** (аналог WinDirStat, только вручную), **журнал ошибок** с фильтром по уровням и сводкой за 24 ч.
- **👥 Карточка AD и регистрация** — атрибуты, группы, смена пароля (одно окно: пароль крупно, карточка для сотрудника), мастер нового пользователя с шаблонами.
- **🏢 Парк** — фоновый сканер, сводка «Внимание», массовый пинг + Wake-on-LAN, ПО и hotfix («у кого установлено 1С 8.3.22?»), входы 4624/4625, сравнение двух ПК, свободный IP **со сверкой с DHCP**, Excel-опись.
- **🧰 Массовые операции и экспорт** — Ctrl/Shift-выделение → группы, блокировки, пароли; XLSX/CSV.
- **🔒 Безопасность** — LDAPS, DPAPI/keyring, экранирование LDAP/SQL/имён узлов, журнал действий, роли по группам AD (право «ПК» и право «AD» независимо), диагностика — только чтение, копия БД перед миграцией.
- **🧩 Расширяемость** — плагины (`Action`-класс → кнопка), CLI (`adk --find … --json`), серверный режим `adk --serve`, ru/en, 10 тем (5 тёмных / 5 светлых) + свои цвета, единый набор контурных иконок.

Полный список с деталями и горячими клавишами — **[docs/FEATURES.md](docs/FEATURES.md)**.

## 🚀 Быстрый старт

**Готовый `ADK.exe` (без Python):** скачайте `ADK-<версия>-win64.zip` из **[Releases](https://github.com/AgentSharik/ADK/releases)**, распакуйте (внутри `ADK.exe` и папка `_internal`, лежат рядом) и запустите.

**Из исходников:**

```bash
git clone https://github.com/AgentSharik/ADK.git && cd ADK
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Первый запуск: ADK создаёт `Documents\ADK\config.ini` (параметры домена пробует определить сам, образец — `config.example.ini`) и спрашивает, **где лежит или будет лежать база** — существующую подхватит, новую создаст и после входа сам наполнит парком (ПК, IP, кто работает, принтеры).
💡 Ставьте ADK на **один** ПК или сервер, остальным — ярлык на его `ADK.exe`: база будет одна.
Подробно (зависимости, PyCharm, откуда брать данные домена, `use_ssl`, роли, серверный режим, плагины, сборка своего exe): **[docs/INSTALL.md](docs/INSTALL.md)**.

## ⚠️ Ограничения

- Сканер, удалённые действия (PowerShell/WinRM/WMI), здоровье ПК, DHCP и хоткей — только Windows; ядро и тесты идут везде.
- База — один файл SQLite в обычном режиме журнала (работает через сетевые папки): для отдела ADK и база живут на сервере, у остальных ярлык; парк сканирует один экземпляр.
- `ADK.exe` не подписан сертификатом — SmartScreen предупредит при первом запуске (что делать — в [INSTALL](docs/INSTALL.md)).
- WoL и автоопределение MAC — в одном L2-сегменте; «Входы за 24 ч» требуют права читать журнал Security удалённо.

## 📜 История

Проект начинался как внутренняя утилита-монолит, созданная в короткие сроки. Затем прошёл аудит и непрерывное развитие:

- **1.x → 2.0:** модульная архитектура, LDAPS, потокобезопасность и автоматические тесты.
- **3.0 → 3.1:** ребрендинг в **ADK**, инструменты для парка ПК, CLI, серверный режим.
- **3.2:** S.M.A.R.T., карта диска, журнал ошибок Windows, DHCP, карта подсети, живой опрос принтеров.
- **3.3:** меню «Питание ПК», независимые роли («ПК» и «AD»), диагностика, надёжное хранение паролей.
- **3.4:** 10 тем оформления, единые контурные иконки, объёмные элементы управления.
- **3.5:** автоопределение параметров домена AD, мастер «где база?» при первом запуске с автонаполнением, опрос парка без базы, единый запуск PowerShell, GitHub Release по тегу.
- **3.6 (актуальная):** сохранность базы — обычный режим журнала (переносится на сервер), сторож зависшего запроса, резервные копии каждые 6 ч, один сканер на общую базу; SQLite — единственный движок.

Подробная история изменений по каждой версии — в **[CHANGELOG.md](CHANGELOG.md)**.
